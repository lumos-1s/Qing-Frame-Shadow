# 清框影 · 图层边框设计

一个「边框」是一份 **图层 JSON**：`{ "templateName": "名字", "layers": [ ... ] }`。
清框影直接把它当模板套到用户照片上——照片、调色、裁切、撤销都不会被破坏。
文件放在 `frames/` 下，如 `frames/a1.json`。

**不要改引擎源码，也不要改内置预设。你的产物只有 `frames/*.json`。**

## 硬规则（先读）

1. **必须有且只有一个 `photo` 图层**：它就是照片的位置和大小，画布比例由它决定。
2. **顺序就是层级**：`photo` 之前的图层在照片下面（底色 / 卡纸 / 背景），`photo` 之后的图层在照片上面（文字 / 线条 / 装饰）。
3. **坐标是 0..1 的比例**，相对画布宽高；不要写像素。
4. **文字必须带 `maxW` 和 `maxLines`**：正文 `size` 用 0.02–0.055；海报级展示字可用 0.07–0.12（限一行短句）。超过 0.13 会被体检判错，引擎硬夹到 20% 画布高。
5. **主体必须可读**：任何不透明层盖住照片不超过一半；压图文字要用实色条块垫底或阴影保证对比。照片槽位短边不小于画面的 45%。
6. **写完必须跑 `qfs-frame check`**：0 错误才算完成；再用 `preview` 出图看一眼。体检口径与引擎同源，会抓多/缺 `photo`、未知图元、错名字段（`width`/`fontSize` 这种会被静默忽略）、文字缺 `maxW`/`maxLines`、`size` 超限、越界、大面积盖照片。

## 命令

在仓库根目录：

```sh
node tools/qfs-frame.js                      # 打印本手册
node tools/qfs-frame.js init --blank "名字" -o frames/a1.json   # 起一份能过体检的图层骨架
node tools/qfs-frame.js check frames/a1.json # 体检；也可 check frames 整批
node tools/qfs-frame.js preview frames/a1.json                  # 出 frames/a1.preview.png
node tools/qfs-frame.js preview frames --image photo.jpg -o .tmp/previews  # 真实照片 + 整批
```

`preview` 内部会自动转交 Electron，直接 `node` 调用即可；不给 `--image` 时用内置合成底图。

## 图元格式

```json
{ "type": "photo", "x": 0.08, "y": 0.08, "w": 0.84, "h": 0.70, "radius": 0.01, "fit": "cover" }
{ "type": "rect", "x": 0.05, "y": 0.05, "w": 0.90, "h": 0.90, "radius": 0.02,
  "fill": "#ffffff", "fillOpacity": 0.9, "stroke": "#dcba79", "strokeWidth": 2 }
{ "type": "circle", "cx": 0.5, "cy": 0.2, "r": 0.08, "fill": "#129e78" }
{ "type": "line", "x1": 0.1, "y1": 0.5, "x2": 0.9, "y2": 0.5, "color": "#dcba79", "width": 2, "dash": [4, 4] }
{ "type": "text", "x": 0.5, "y": 0.92, "text": "QINGFRAME", "size": 0.03, "color": "#f2e4c4",
  "align": "center", "weight": 600, "letterSpacing": 0.1, "maxW": 0.8, "maxLines": 1 }
```

- `radius`：小于 1 按短边比例，大于等于 1 按像素；不写就是直角。
- `fillOpacity` / `opacity`：0..1；`shadow: {color, blur, offsetX, offsetY, opacity}` 可选。
- 颜色支持 `#rgb` / `#rrggbb` / `#rrggbbaa` / `rgb()` / `rgba()`。
- `fit`：`cover`（默认，裁切铺满）或 `contain`（完整放进槽位）。
- `line` 的 `dash` 是像素单位。

## 文字约束

- `size`：相对画布高。正文 0.02–0.055；展示字 0.07–0.12，`maxLines: 1` 且只放短句；引擎硬夹到 6px–20% 画布高。
- `maxW`：这一行最宽能占画布的比例，建议 0.6–0.9；展示字可以更窄。
- `maxLines`：最多几行；超出会缩字号、再截断成 `…`。
- `align`：`left` / `center` / `right`；`x` 是对齐锚点。
- `letterSpacing`：相对字号的比例（>1 视为像素）。
- 压图文字可以存在，但必须保证对比：实色条块承托或阴影，别用和照片主体相近的明度硬叠。

## 构图语法（四款四族）

先定构图，再配色。每款先写一句「构图句」：照片怎么放、文字扮演什么、母题是什么。
四款必须用四种不同语法；同一骨架只换颜色或一句文案，不算四款。用户明确要求四款同风格/同骨架时，先服从用户。

- **满版压字**：照片铺满或出血，超大标题/编号压在照片上，用实色条块垫底或阴影保证可读；信息退到角落。
- **偏置分栏**：照片占 55%–75% 宽或高，锚定一角/一侧；另一侧用整块留白、色块和纵向信息形成不等距版式。
- **档案票据**：像档案卡/索引页——细线网格、页眉页脚、编号、日期、打孔圆点、标签块；照片是贴上去的图版。
- **网点印刷**：两到三色印刷语言——重复圆点矩阵、错位实色块、粗描边、裁切/套准标记；不用细金线。
- **取景器**：相机取景语言——四角括号、三分线、中心十字、边缘刻度、曝光参数；线可以压在照片上。
- **字体海报**：照片只是海报里的一个图版，巨大编号/单字/短句做主视觉，信息沿边或跨版排。
- **纸片拼贴**：错位矩形纸片、投影、胶带条、手写式短句、裁切线；允许小色块压住照片角（不超过 25%）做层次。
- **极简光学**：大面积留白/单色，照片偏置，只用一条发丝线、一个极小标记、一个短句；靠比例和空白。

### 反默认

除非用户点名，不要默认做这些：

- 居中照片 + 四边等宽留白 + 底部一行字。
- 直接复刻内置预设已有的邮票齿孔、拍立得白边、报纸头版、胶片齿条、票根、杂志封面。
- 四款同一骨架，只换配色/字体/一句文案。
- 用无意义的圆点、线条、贴纸填满画面。

### 可用的创新杠杆

- **不对称**：一边留 4%，另一边留 18%；照片偏置而不是居中。
- **照片出血/贴边/压角**：可以贴边或占画面 55%–75%，把其余交给文字；至少一款可以让照片碰到画布边。
- **文字当图形**：压图、贴边、竖排（逐字换行）、超大编号、沿边信息带；至少一款让文字成为主视觉。
- **印刷/档案语言**：2–3 个粗色块、重复圆点、刻度、裁切标记、套准十字、半透明叠色（引擎只支持实色，用叠层模拟）。
- **配色不设限**：从照片主色/辅色或一个明确概念来；可以高饱和双色、黑白 + 一个荧光点色、纸张色 + 墨色，不必每款都用暖灰金。
- **至少两款各用一个杠杆，至少一款第一眼不像相框**（字体海报 / 印刷实验 / 档案页）。

## 交付

在 `frames/` 下写 `a1.json` / `a2.json` / `a3.json` / `a4.json`，每份一个完整对象。
`templateName` 写能看出构图或概念的名字，不要「方案一」。

```json
{
  "templateName": "偏置档案 · 2026",
  "layers": [
    { "type": "rect", "x": 0, "y": 0, "w": 1, "h": 1, "fill": "#e9e2d2" },
    { "type": "rect", "x": 0, "y": 0, "w": 0.58, "h": 1, "fill": "#141414" },
    { "type": "photo", "x": 0.06, "y": 0.08, "w": 0.46, "h": 0.84, "radius": 0.004, "fit": "cover" },
    { "type": "text", "x": 0.62, "y": 0.22, "text": "2026", "size": 0.12,
      "color": "#1a1a1a", "align": "left", "weight": 700, "maxW": 0.32, "maxLines": 1 },
    { "type": "line", "x1": 0.62, "y1": 0.4, "x2": 0.94, "y2": 0.4, "color": "#8a6d3b", "width": 1 },
    { "type": "text", "x": 0.62, "y": 0.46, "text": "ARCHIVE / 35MM", "size": 0.024,
      "color": "#6b5636", "align": "left", "letterSpacing": 0.12, "maxW": 0.32, "maxLines": 1 }
  ]
}
```

交付前：`check` 全部 0 错误，`preview` 的图自己看过一遍，确认四款真的用了四种构图而不是四套配色。
回复只写「完成」+ 文件路径 + 一句设计说明，不要输出 JSON 正文。
