# 《清框影》抖音宣传脚本 v2

> v2 基于老大自己的口播草稿改写。骨架、语气、事实全部保留，只做四件事：
> **补钩子的画面、砍掉会掉完播的段落、把"求 star"翻译成人话、修掉会被限流的说法。**

---

## 0. 你原稿里最值钱的三句话

这三句不要动，它们是这条视频的**信任地基**，任何"更专业"的改写都会把它毁掉：

1. **「一个人，三个月，用 AI 开发」** —— 独立开发者叙事，观众天然愿意宽容 bug
2. **「之前只有我朋友在用」** —— 比任何"已有 xx 万用户"都可信，因为它不吹
3. **「还在逐步完善、修复 bug」** —— 主动示弱，反而挡住了差评

现代抖音观众对"完美软件广告"的免疫力极高，对"一个真人在修 bug"几乎没有抵抗力。

---

## 1. 原稿要改的四处

| 原话 | 问题 | 改成 |
|---|---|---|
| 「像这样这样还有这样的边框」 | 画面在动、观众不知道在看什么 | 每张图左上角打角标：`杂志框` `邮票框` `撕纸框`，同时念「像这样、这样，还有这样」 |
| 「你是不是还在用手机上的加框软件」 | 好钩子，但少了"疼" | 后面必须紧跟**七步流程图**，让"繁琐"变成看得见的东西 |
| 「联系主播拿软件」 | 抖音对导流极敏感，"加我拿软件"容易被压 | 「评论区扣个 1，我发你」——评论区互动反而喂流量 |
| 「点一个免费的 star」 | 一半观众不知道 star 是啥，且 star 本来就不花钱，"免费"显得奇怪 | 「顺手点个 star，就是 GitHub 上那颗星星，点一下别人就能搜到它」 |

小笔误也顺手修了：`91中` → 91 种、`start` → star、`煮波` → 直接说「我」（口播里自称"主播"会拉开距离，说"我"更近）。

## 2. 主版脚本 · 61 秒（竖屏 1080×1920）

口播共约 305 字，按每秒 5 字卡表。念快一点 58 秒、慢一点 63 秒，都在合理区间，别为了凑整数把语速拧紧。

| 时间 | 画面 | 口播 | 屏幕字幕 / 音效 |
|---|---|---|---|
| **0–6s** | 三张成片各 2 秒硬切：**VHS 录像带 → 邮票 → 撕纸**（从最炸的开始，别用最普通的） | 像这样、这样，还有这样的边框——你是不是还在用手机上的加框软件？ | 角标：`杂志框` `邮票框` `撕纸框`<br>音效：每切一次"嗒" |
| **6–15s** | 七步流程图横着推过去：手机相册 → 微信传输助手 → 保存 → 打开 App → 选图 → 加框 → 再传回电脑 | 拍完在电脑里，想加个框，得先传到手机，加完再传回来。一张两张还行，一百张就是折磨。 | 大字：**一张图 7 步**<br>副字：一百张就是折磨 |
| **15–23s** | 清框影窗口拉开 → 直接铺满 91 款预设墙 | 所以我自己写了一个。一个人，三个月，AI 当搭子，做成了电脑版——《清框影》，现在 0.1.29。 | **一个人 · 3 个月 · AI 搭子**<br>右下角小字：v0.1.29 |
| **23–32s** | 预设墙全景（一屏看全）→ 鼠标点选 → 中间画布即时换框 → 再点什么都没关系，随便切 | 91 种边框，市面上流行的基本都在里面。我做了个预设墙，一屏看全，点哪个用哪个，不用一个个试。 | **91 种 · 预设墙一屏看全** |
| **32–39s** | GitHub 更新日志往上一滚，红字 `fix` 一条条划过 | 之前只有我朋友在用，现在还在补 bug。版本号才到 0.1.29。 | 大字：**还在补 bug**<br>（这句是全片最加分的一句） |
| **39–51s** | 五连快切，每段 2 秒：① 整个文件夹拖进来，几十张缩略图落位 ② RAW 缩略图带相机型号 ③ 调色拉曲线 ④ 拼图两行字幕（字号明显不同）⑤ 切图 4×4 → 沉浸式看图 | 但它不只是加框。RAW、JPG、WebP、PNG 能批量进、批量出，整个文件夹拖进来也行；调色、拼图、切图、沉浸式看图，都在同一个窗口。 | 左下角常驻小字条：**RAW / JPG / WebP / PNG · 文件夹导入** |
| **51–61s** | 桌面图标 + 一张刚导出的成片"啪"地拍在桌上；说到"评论区"时画面切到评论区动图 → 定格 | GitHub 上开源，想要的评论区扣个 1。有问题、想要什么功能，也在评论区问，我一条条看。顺手点个 star——就是那颗星星，点一下，别人就能搜到你。 | **开源 · GitHub**<br>**有问题评论区问**<br>结尾留 1.5 秒黑场 |

> 第 39–51 秒是全片唯一的"功能高潮"，**必须每 2 秒一刀**。切得慢一点，前面攒的信任就白攒了。
>
> 想压到 45 秒：砍掉"还在补 bug"那段（但我不建议——那是全片最像人的一段），或者把预设墙从 9 秒压到 5 秒、只放 4 款。

### 结尾为什么改了说法

原话「也欢迎各位提出问题」方向是对的，但**"欢迎"太客气、没有承诺**。观众听完不知道你会不会真的回，于是就不问了。

改成「有问题、想要什么功能，也在评论区问，**我一条条看**」——给了三个具体承诺：**问什么（问题/需求）、在哪问（评论区）、会怎样（我一条条看）**。可信度立刻不一样。

而且这句话顺带完成了一件很重要的事：**把"求 star"从索取变成了交换**。观众看到"你愿意一条条回"，点星星就不再是白给。

## 3. 连续口播版（录音时直接照着念，别看表格）

> 像这样、这样，还有这样的边框——你是不是还在用手机上的加框软件？
>
> 拍完在电脑里，想加个框，得先传到手机，加完再传回来。一张两张还行，一百张就是折磨。
>
> 所以我自己写了一个。一个人，三个月，AI 当搭子，做成了电脑版——《清框影》，现在 0.1.29。
>
> 91 种边框，市面上流行的基本都在里面。我做了个预设墙，一屏看全，点哪个用哪个，不用一个个试。
>
> 之前只有我朋友在用，现在还在补 bug。版本号才到 0.1.29。
>
> 加框只是一个。RAW、JPG、WebP、PNG 能批量进、批量出，整个文件夹拖进来也行；调色、拼图、切图、沉浸式看图，都在同一个窗口。
>
> GitHub 上开源，想要的评论区扣个 1。有问题、想要什么功能，也在评论区问，我一条条看。顺手点个 star——就是那颗星星，点一下，别人就能搜到你。

念的时候注意三处停顿：`一个人，| 三个月，| AI 当搭子` —— 三个词之间各停 0.3 秒，这是全片唯一该慢下来的地方。**结尾"我一条条看"也要慢**，那四个字是整条视频唯一的人格证明，念快了就变成客套话。其余全部用平时的语速，别端着。

## 4. 完整版 · 92 秒（发主页置顶 / 合集 / 小红书 / B站）

抖音单条超过 70 秒，完播率会掉一截，所以完整版**不投抖音信息流**，只做「主页第一屏」和跨平台。多出来的 34 秒塞这些：

| 时间 | 内容 | 口播 |
|---|---|---|
| 20–28s | 预设墙点开单款，**缩略图换成自己下载的图**（⚠️ 见文末待确认项） | 连每一款的封面图都能换成你自己下的，看着顺眼才点得下手。 |
| 38–48s | 左侧栏导入调色预设（拖入 `.xmp`，列表瞬间长出一排） | 左边这一栏，Lightroom 的调色预设直接拖进来就能用，我平时攒的那堆终于不用开 LR 了。 |
| 48–58s | EXIF 参数自动排版（★ 这是你原稿漏掉的王牌，见下） | 还有个我很得意的：相机型号、光圈、快门、ISO，它自己读 EXIF，排好版压在框上，不用手打。 |
| 58–72s | 批量导出：选 20 张 → 导出面板 `8192px` / `Display P3` → 文件夹里 20 张落位 | 二十张一起出，最高 8192 像素，P3 和 Adobe RGB 都能嵌 ICC，发小红书和印出来都不掉色。 |
| 72–92s | 同主版结尾，但多说一句 | GitHub 上开源，想要的评论区扣个 1。用得不对、少了什么功能、或者你只是想知道某个按钮是干嘛的，都在评论区问，我一条条回。顺手点个 star，对我这种一个人做的，真的挺重要。 |

**★ 关于 EXIF 那段**：你原稿里没提，但这是整个软件最"别人没有"的画面——同类工具只会套框，不会读参数排版。建议至少在完整版里补一段；要不要提到主版，看你更想吸引"摄影圈"还是"普通发朋友圈的人"。

## 5. 一次拍摄，四条内容

你手上的素材其实够拆四条，别只发一条就完：

1. **主版 58 秒**（痛点 → 我做了一个 → 功能 → 求 star）—— 主推
2. **切片 A · 18 秒**：只用"七步流程图 + 预设墙横扫"，标题《手机加框到底有多麻烦》，不带任何软件信息，纯共鸣，末尾 3 秒才露软件
3. **切片 B · 20 秒**：纯边框展示，91 款卡点快切，标题《91 种边框，挑一个》，BGM 主导、几乎不说话
4. **切片 C · 25 秒**：纯功能，文件夹导入 + 批量导出，标题《一百张照片一起加框》，面向"批量出图"的人

四条共用一次录屏，切片 A 是涨粉主力（共鸣类完播高），主版是转化主力。

## 6. 「欢迎提问」不是客套，是运营动作

求问题这件事有三层回报，值得在结尾专门留出 4 秒：

**① 提问是最低门槛的互动。** 点赞是"顺手"，提问是"表达自己"。同样一条视频，让观众点赞的转化率远低于让他打一行字。而评论数在推荐权重里，比点赞重得多。

**② 问题是最好的第二条视频。** 你回完一轮，把「问得最多的 5 个问题」剪成一条 30 秒，几乎零成本，而且这类视频完播极高——因为每个提问的人都想知道自己的问题有没有被念到。你甚至可以开头就说「上条视频有人问……」，天然带续集感。

**③ 问题是需求的免费调研。** 一个人做软件，最贵的就是"不知道该加什么功能"。评论区问什么，就先做什么，比你自己拍脑袋准十倍。

**但要分流，否则评论区会变成 Bug 收容所：**

| 类型 | 去哪 | 话术 |
|---|---|---|
| **装不上 / 报错 / 闪退** | GitHub Issues | 「这个麻烦你去 GitHub 提个 issue，带上系统版本和截图，我好排查，也不会漏」 |
| **怎么用 / 某个按钮干嘛的** | 留在评论区 | 直接回，回得越笨拙越好——太专业的回答会劝退新手 |
| **想要某个功能** | 留在评论区 + 让他去 issue 里加一句 | 「记下来了，你在 issue 里再留一句，我按呼声排优先级」 |
| **和别的软件比谁好** | **不接** | 「它有它的好处，我这个主要是给不想上传照片的人用的。」一句话带过，别吵 |

第四条最重要。**一旦你在评论区跟人比功能，这条视频的评论区就变成了战场，路人会直接划走。**示弱一句话，比赢一场辩论值钱。

## 7. 录制与剪辑（关键几条）

**录屏**
- 1920×1080 或 2560×1440，系统缩放**保持 100%**（150% 会让 UI 变大但也变糊）
- OBS：60fps / CQP 18 / 录 MKV 防崩
- 鼠标速度压到平时 60%，后期 1.2 倍速，运镜才"稳"
- 关掉：桌面图标、微信通知、**任务栏时钟**（多镜头之间时钟会跳，观众会发现你在补拍）

**竖屏合成（最容易翻车的一步）**
- 1080×1920 时间线，**别整屏缩进去**——缩完字小于 20px，手机上就是一团糊
- 录屏放大到 150%，只露「画布 + 右侧参数面板」；要展示左侧列表就用**位置关键帧平移**，不要缩小
- 安全区：顶部约 260px、底部约 480px 会被抖音界面压住，关键信息放中间

**节奏与声音**
- 每 2.5–3 秒换镜，工具类视频超 4 秒不动，完播断崖
- 字幕 48–56px，一行不超过 12 字
- 三个音效承包一半节奏：套框"嗒"、切页签"唰"、导出"叮"
- BGM 压到 -22dB 以下；**自己配，别用 AI 配音**——工具类观众对机器音零信任

**封面**
- 用「原片 | 成片」左右分屏 + 大字 **「手机加框，7 步」**
- 别拿软件 logo 当封面，没人点

## 8. 作品描述 · 话题 · 评论区

### 先说抖音的规则

- 信息流里只露**前 1–2 行（约 40–55 字）**，后面折进「展开」。所以：**第一行是第二个钩子，不是标题的复读机。**
- 视频负责让人「看完」，描述负责让人「评论」。两者不能干同一件事。
- 纯网址会被屏蔽，但写「GitHub 搜 xxx」这种**文字指路**是安全的。
- 描述里换行有效，但每换一行就多吃一行展示位，别写成散文。

### 别用公式

我上一版在这里写了「身份 → 数字 → 态度 → 问句 → 指路」五个步骤。删了。

那种公式就是 AI 味的源头：套出来每一条都工整、都完整、都一个味儿。真发的时候，四条视频里有一两条干脆不提问、不总结、不打标签收尾，反而像真的。

唯一值得保留的：**描述第一行说一件具体的事**，别抒情。

### 关于 vibe coding，放哪一行很重要

这个词值钱，因为它同时干三件事：解释了你为什么一个人能做完、自带一层自嘲、还是当下开发者圈的热词。

但它对摄影爱好者是黑话。所以位置要卡准：

**放进描述第二行，别放进第一行。** 第一行照旧说具体的事（软件是什么、解决了什么），第二行才补一句"一个人 vibe coding 了三个月"。懂的人会心一笑，不懂的人直接跳过，不损失信息。

**口播里不用说这个词。** 说"AI 当搭子"就行，所有人都听得懂。视频负责让人听懂，文字负责接搜索流量，这两件事不用挤在同一句话里。

**标签里用 `#vibecoding`，但一定带上 `#AI编程`。** 英文标签在抖音的搜索池子很小，中文大词才有量。两个都放，一个接精准人群，一个接大盘。

**要预备一句话挡质疑。** 用这个标签，一定有人回"AI 写的能有质量吗"。别辩解，就回：对，所以 bug 不少，我在一条条改。这句比任何解释都好使。

### 第五种用法：单独做一条技术圈向的

如果你愿意再拍一条，vibe coding 可以直接当主角。这条在技术区容易起量，但来看热闹的多、下载的少，定位是涨粉。

**标题**：用 vibe coding 三个月，我写了个 91 个边框的修图软件

**描述**
```
三个月，基本是一边跟 AI 聊，一边把东西做出来的

从"帮我把这张图加个框"开始，聊到 91 个边框、RAW 直读、批量导出 8192px

最崩的一次是【填你的真实翻车】，改了两天

现在 0.1.29，还在改

Windows，开源，GitHub 搜 Qing-Frame-Shadow
#vibecoding #AI编程 #独立开发 #开源 #清框影
```

这条的重点不是软件，是过程。技术圈爱看的是"你怎么指挥 AI 的"，所以画面该露的是你的对话、报错、回滚，不是成片。

### 想让文案像人写的，八条

1. **删掉所有破折号。** 中文写作里破折号是 AI 的高频指纹，真人很少用，用也是偶尔一次
2. **别写三段式排比。** "崩过、卡过、骂过"这种三连，读起来像年会 PPT
3. **每段长度必须不一样**，其中至少有一句只四五个字
4. **不用"真的""其实""简直""绝了""救命"** 这些词，一个都别留
5. **留一句没用的话**。跑题的、自嘲的、突然插一句的，人才会这么写
6. **不要每段都以问句结尾**。四段里有一段不问，反而更像随手发的
7. **标点可以不全**，句号该省就省
8. **数字要怪一点**。写 91，不写"九十多"；写 0.1.29，不写"最新版本"

还有一条最要紧的：**留一处只有你知道的细节。** 你朋友的原话、你调某个毛病调了几天、某款边框改了几版，随便一处都行。这种细节抄不走，也是唯一能证明"这是人做的"的东西。

下面三个空，你挑一个填进去，效果比任何修辞都强：

- 朋友当时说的是「__________」
- 有一款边框我改到第 ___ 版才满意
- 让我最烦的一个 bug 是 __________

### 话题怎么配

**只放 5–6 个，别贪多。**堆到十几个会被判标签堆砌，反而降权。结构是「一大 + 两精准 + 一人格 + 一品牌」：

| 位置 | 作用 | 示例 |
|---|---|---|
| 第 1 个 | **大流量泛词**，进大池子 | `#摄影` / `#摄影后期` |
| 第 2–3 个 | **精准词**，找对人 | `#修图软件` `#边框` `#RAW` `#批量修图` `#排版` |
| 第 4 个 | **人格词**，进创作者流量 | `#独立开发` `#vibecoding` `#AI编程` `#开源` |
| 第 5 个 | **品牌词**，长期资产 | `#清框影` |

**关于 `#清框影`**：自造标签一开始点进去是空的，这是正常的。每条都带，发到五六条就会攒出内容，之后有人搜软件名能直接落到你的合集里。**这是你唯一能自己拥有的流量入口，别省。**

**别用**：`#热门` `#上热门` `#涨粉` `#互赞`——这些是明确的垃圾标签信号，算法认得出。

### 发布设置（顺手就能做对）

- **时间**：摄影类晚 20:00–23:00；独立开发/工具类午 12:00–13:00、晚 21:00 后
- **合集**：四条都塞进一个合集《清框影 · 一个人做的修图软件》，主页停留时长会明显变好
- **封面统一**：四条封面用同一套字体和配色，主页看起来像一个系列，不是四条散装视频
- **定位**：别加无关城市定位，蹭不到流量还会让本地推流跑偏

## 9. 待确认 & 别做的事
